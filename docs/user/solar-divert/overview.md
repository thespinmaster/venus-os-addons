# Solar Divert Overview

This add-on is not available yet

This addon manages any excess solar. When not on shore power, once the battery reaches 100% charge. A CerboGX relay is triggered to on. If/when the battery power reduces to a pre-defined level say 92% Then relay is tiggered to off.
One use for this is for fridges that support solar+ (S+) (basicaly the same a vehacle D+). When the fridge detects a S+ signal (the relay is on) the fridge switches to battery, and switches back to Mains/Gas when there is no signal (the relay is off).

## Prerequisite

Install [Opkg Manager](../vespera/setup.md) first before using this add-on.
